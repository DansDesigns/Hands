# Contributing to Freehand: Spatial Computing

Thanks for helping with Freehand's hand-tracking, gestures, user interface and accessibility.

1. Open an issue for large changes, and keep pull requests focused.
2. Include tests or instructions to reproduce behaviour where practical, on Windows and/or Linux.
3. Do not commit virtual environments, personal calibration data, database indexes, downloaded or restricted third-party models, signing keys or generated caches.
4. Don't add D1, STT/TTS, facial recognition or assistant file indexing back into Freehand. These belong in the separate assistant project.
5. Respect GPL-3.0-or-later for Freehand source and the separate licence requirements for third-party assets.
6. Only contribute work you own or have the rights to license; identify all third-party content and provenance.
7. For accepted contributions, follow [`CONTRIBUTOR_LICENSE_AGREEMENT.md`](CONTRIBUTOR_LICENSE_AGREEMENT.md) if the maintainers require its explicit agreement in the pull request.
