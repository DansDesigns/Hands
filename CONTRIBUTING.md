# Contributing to Spatial Desktop

Thank you for helping improve Spatial Desktop.

1. Open an issue first for large changes so the approach can be discussed.
2. Keep pull requests focused and include tests where practical.
3. Do not commit virtual environments, downloaded models, personal calibration
   data, local indexes, credentials, or generated caches.
4. Respect the third-party licences for libraries and models.
5. By submitting a contribution, you confirm you have the right to submit it and
   understand that maintainers may include accepted contributions in future releases.

A project licence will be selected and added separately by the maintainer. Until
then, do not assume that public availability grants permission to redistribute or
commercially use the project.
